# Catatan Scaffold Awal

Dokumen ini dahulu berisi output setup template React/Vite, termasuk path `/mnt/agents/output/app` dan daftar komponen saat scaffold dibuat. Informasi itu **historis**, bukan petunjuk menjalankan checkout Windows saat ini.

Gunakan [README.md](README.md) untuk menjalankan proyek, [project.md](project.md) untuk status terkini, dan [CONTEXT.md](CONTEXT.md) untuk batas domain/implementasi. Versi dependency dan script yang tersedia mengikuti `package.json` serta `package-lock.json`; inventaris komponen mengikuti `src/components/`.
