Pendekatan Implementasi

Tiga opsi untuk struktur kode — rekomendasi ada di opsi 1

1

✅ Modular Pages (Rekomendasi)

Struktur: Setiap pipeline phase jadi page folder sendiri

  • src/pages/production-order/ — form create, pull action
  • src/pages/cutting-phase/ — input totalCutting, locked view
  • src/pages/sewing-phase/ — entry log + progress bar
  • src/pages/finishing-sync/ — import batch form
  • src/pages/invoicing/ — invoice list, payment form
  • src/data/pipelineData.ts — semua tipe + mock data baru

Mudah dipahami, scalable, dan mudah ditambah auth nanti.

2

Feature Slices

Struktur: src/features/production-order/, src/features/cutting/, dll

  • Setiap feature punya components/, hooks/, types/ sendiri
  • Lebih terisolasi, cocok untuk tim besar
  • Overhead boilerplate lebih banyak
3

Semua di App.tsx (Tidak Direkomendasikan)

Cara: Tambah state management + render logic di App.tsx

  • App.tsx sudah 677 lines — akan jadi ribuan lines
  • Sulit dipelihara. Hanya untuk prototype cepat.
