💡 Production Monitoring mencakup seluruh pipeline produksi (Cutting → Sewing → Finishing) dalam satu halaman. Setiap tab menampilkan data yang relevan untuk phase tersebut. Invoice terpisah di section Finance.

🔑 Ringkasan Struktur

Section Item Sidebar Keterangan
Production 📊 Production Monitoring Satu halaman. Internal tabs: All Orders · Cutting · Sewing · Finishing
Master Data 📦 Master Product, 📡 Raw Monitoring, 🚚 Import, 🎯 Target Jahit Data referensi (read-only sebagian)
Finance 💰 Invoicing Terpisah dari pipeline — ranah finance
System 📈 Reports, ⚙️ Settings Tools system-wide

✅ Flow ERP: Master Data (referensi) → Production Monitoring (operasional pipeline) → Invoice (finance). Cutting, Sewing, Finishing ada dalam satu halaman Production Monitoring sebagai tab, bukan sidebar terpisah. Invoice dipisah karena ranahnya berbeda (finance).
